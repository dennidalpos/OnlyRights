Privacy & GDPR Policy Informativa Privacy e GDPR

Last updated: July 15, 2026 Ultimo aggiornamento: 15 Luglio 2026

1. 100% Offline & Local Isolation 1. Esecuzione 100% Offline e Locale

OnlyRights NtfsAudit does not transmit any scanned data, folder structures, permissions, or system metadata to external web servers, cloud APIs, or third parties. The entire auditing process is compiled and run locally on your Windows environment. OnlyRights NtfsAudit non trasmette alcuna struttura di cartelle, permessi, dettagli di scansione o metadati di sistema a server esterni, API cloud o terze parti. L'intero processo di audit viene compilato ed eseguito localmente sul tuo ambiente Windows.

There is no telemetry, tracking, or remote analytics instrumentation embedded in the software. Nel software non è integrato alcun sistema di telemetria, tracciamento o analisi remota dei dati.

2. Scan Credentials Protection 2. Protezione delle Credenziali di Scansione

When network share scanning requires alternate credentials, they are protected using Windows Data Protection API (DPAPI) with a LocalMachine scope. Quando la scansione delle condivisioni di rete richiede credenziali alternative, queste vengono protette utilizzando le API di protezione dei dati di Windows (DPAPI) con ambito LocalMachine.

  • DPAPI Scope: Scans are isolated, and raw credential payloads are decrypted only when impersonating targets during the scanning execution. Ambito DPAPI: Le scansioni sono isolate e le credenziali in chiaro vengono decifrate solo al momento dell'impersonamento durante l'esecuzione.
  • Zero-Credential Exports: Configured passwords, secrets, or tokens are strictly stripped out of `.ntaudit` archive metadata (meta.json), newline-delimited JSONL export files, and error logs. Esportazioni Sicure: Password, segreti o token configurati vengono rigorosamente rimossi dai metadati dell'archivio `.ntaudit` (meta.json), dai file JSONL esportati e dai log degli errori.

3. GDPR & Personal Data Governance 3. GDPR e Gestione dei Dati Personali

During NTFS scanning and Active Directory synchronization, OnlyRights NtfsAudit reads and maps Security Identifiers (SIDs) to usernames and domain group memberships. Under the General Data Protection Regulation (GDPR), these usernames and identifiers constitute personal data (identifiable network details). Durante la scansione NTFS e la sincronizzazione con Active Directory, OnlyRights NtfsAudit acquisisce e mappa i Security Identifier (SID) associandoli a nomi utente e appartenenza a gruppi di dominio. Ai sensi del Regolamento Generale sulla Protezione dei Dati (GDPR), questi identificatori costituiscono dati personali.

Because the application suite runs completely offline, the organization executing the scans operates as the sole Data Controller. OnlyRights developers have no access to your archives, file paths, or directory reports. It is the responsibility of the Data Controller to secure all generated `.ntaudit` database archives, Excel spreadsheets, and scan logs. Poiché la suite software viene eseguita interamente offline, l'organizzazione che esegue le scansioni funge da unico Titolare del Trattamento (Data Controller). Gli sviluppatori di OnlyRights non hanno alcun accesso ai tuoi archivi, percorsi file o report di directory. È responsabilità del Titolare del Trattamento proteggere tutti gli archivi `.ntaudit` generati, i fogli Excel ed i file di log.

4. Windows Service Permissions 4. Privilegi del Servizio di Background

The optional background scanning service (`NtfsAudit.Service`) is staged under `%ProgramData%\NtfsAudit` and processes schedules created within the main desktop UI. The service executes using the configured service account identity and decrypts credentials scoped to the local machine boundary, guaranteeing safe execution outside the desktop user's interactive space. Il servizio di scansione in background opzionale (`NtfsAudit.Service`) è posizionato sotto `%ProgramData%\NtfsAudit` ed esegue i compiti programmati pianificati tramite la UI desktop. Il servizio viene eseguito con l'identità dell'account di servizio configurato e decifra le credenziali associate alla macchina locale, garantendo un'esecuzione isolata.
